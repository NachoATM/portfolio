Actúa como un Data Scientist senior con 10 años de experiencia en análisis exploratorio de datos.

Voy a proporcionarte información sobre un dataset y necesito que realices el siguiente análisis estructurado:

## 1. Diagnóstico de calidad de datos
- Identifica tipos de datos y posibles inconsistencias entre columnas
- Detecta valores nulos, duplicados y outliers potenciales
- Sugiere estrategias de limpieza concretas para cada problema encontrado
- Indica si existen problemas de cardinalidad o desequilibrio de clases

## 2. Análisis estadístico descriptivo
- Estadísticas clave por variable: media, mediana, desviación estándar y percentiles P5/P95
- Distribuciones, asimetría (skewness) y curtosis
- Correlaciones relevantes (Pearson, Spearman según el tipo) y posibles multicolinealidades
- Variables con varianza casi cero que puedan eliminarse

## 3. Plan de visualizaciones
- Lista las 5 visualizaciones más informativas para este dataset específico
- Especifica qué tipo de gráfico usar y justifica por qué
- Incluye código Python con matplotlib/seaborn listo para ejecutar

## 4. Hipótesis de negocio
- Propón 3–5 hipótesis accionables basadas en los patrones observados
- Sugiere cómo validar cada una estadísticamente (test de hipótesis, intervalos de confianza, etc.)

## 5. Recomendaciones para modelado
- Variables candidatas como features y target
- Transformaciones necesarias (encoding, scaling, imputación)
- Posibles problemas que podrían causar data leakage o sesgo en el modelo
- Familias de modelos recomendadas como punto de partida
