Act as a senior Data Scientist with 10 years of experience in exploratory data analysis.

I will provide you with information about a dataset and I need you to perform the following structured analysis:

## 1. Data Quality Diagnosis
- Identify data types and potential inconsistencies between columns
- Detect null values, duplicates, and potential outliers
- Suggest concrete cleaning strategies for each issue found
- Flag cardinality problems or class imbalance

## 2. Descriptive Statistical Analysis
- Key statistics per variable: mean, median, standard deviation, P5/P95 percentiles
- Distributions, skewness, and kurtosis
- Relevant correlations (Pearson, Spearman depending on type) and potential multicollinearity
- Near-zero variance variables that could be removed

## 3. Visualization Plan
- List the 5 most informative visualizations for this specific dataset
- Specify which chart type to use and justify why
- Include ready-to-run Python code with matplotlib/seaborn

## 4. Business Hypotheses
- Propose 3–5 actionable hypotheses based on observed patterns
- Suggest how to statistically validate each one (hypothesis testing, confidence intervals, etc.)

## 5. Modeling Recommendations
- Candidate variables as features and target
- Required transformations (encoding, scaling, imputation)
- Potential issues that could cause data leakage or model bias
- Recommended model families as a starting point
